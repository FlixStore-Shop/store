Security & Protection Architecture

  • ✓ scrypt Key Derivation: Passwords hashed with 64-byte cryptographic salts.
  • ✓ Zero SQL Injection: 100% Parameterized prepared statements across all queries.
  • ✓ Rate Limiting Protection: In-memory sliding window defense against brute force.
  • ✓ XSS Defense: Strict sanitization of customer names, reviews, and inputs.
  • ✓ Encrypted Vault: Customer credentials isolated and only revealed to authenticated buyers.
  • ✓ Hardened HTTP Headers: X-Content-Type-Options, X-Frame-Options, strict referrer policies.
